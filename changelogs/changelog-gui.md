## v1.0.0
- Initial release! You must use notShot version 1.4.0 or higher for GUI support.
- No support for `--verbose` or `--active`.
- The GUI searches the folder that it's in for notShot, so it should be left within the installation directory. Assuming it's found, it will display the version alongside the GUI's version.
- Run the GUI by replacing `notshot.py` with `notshotgui.py` in your scripts.
- Running `notshot.py --help` will add what version the GUI is, if it is detected.
